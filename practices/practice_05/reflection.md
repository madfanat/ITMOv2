# Рефлексия по работе

Записано по фактическому процессу AI-агента. Это не выдуманные впечатления
или ответы студента; при защите студент может дополнить собственные выводы.

Две независимые спецификации выявили разрыв ещё до кода: UI предлагал
плоский error, а логика — вложенный error.code/message. Если бы реализацию
начали сразу, браузер не смог бы надёжно отличить timeout от обычной
ошибки. Общий контракт также закрепил request_id в заголовке, demo header,
ручной повтор и правила подсчёта Unicode. Обе роли повторно проверили
итоговые документы до появления app/.

Спецификация изменила архитектуру: синхронный generate из учебного патча
заменён на async Protocol. Таймаут вокруг потока дал бы HTTP-ответ, но
оставил бы работающий вызов в фоне. Для принятого контракта нужен
отменяемый await. Отдельный тест проверяет фактическую отмену coroutine,
а браузерный тест — реальные 10 секунд, доступность health и повтор.

Формулировка «20 000 символов» оказалась неоднозначной: Python len
считает Unicode code points, а обычный JS length — UTF-16 code units.
Выбрали одинаковый подсчёт через Array.from в UI и проверили emoji на
границе 20000/20001. Это пример решения, которое стоит зафиксировать
именно в общем контракте, а не оставить каждой команде по отдельности.

Первые 37 тестов прошли, но независимое ревью нашло реальный недостаток
маскировки: escaped quote оставлял хвост пароля в prompt. Добавлены два
регрессионных теста, сохранён failing run, уточнение внесено в спецификацию,
затем исправлен regex. Итог — 39 тестов. Спеки помогают задать проверяемые
правила, но не заменяют независимый probe и review безопасности.

Spec Kit удобен конституцией и явным разбиением spec/clarify/plan/tasks.
OpenSpec из презентации акцентирует историю changes и sync/archive;
здесь фича помещена в отдельный каталог спецификаций, а состояние
выполнения ведётся в tasks. CLI проверяет инфраструктуру и наличие
документов; смысл контракта проверяли агенты и тесты. Наличие template
само по себе не означает, что домашка работает.

Окружение ограничивало сеть и открытие localhost: зависимости пришлось
скачать с разрешением среды, браузерные проверки выполнить с разрешением
на локальный порт. Это не повлияло на контракт. Важное ограничение
результата — demo provider: надёжность сценария воспроизводима без ключей,
но качество реальной LLM не проверено. Человеческие решения и приёмка
не симулировались; итог подготовлен к самостоятельной проверке на сдаче.
