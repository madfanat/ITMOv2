# Clarify · согласование до генерации кода

Дата: 2026-10-28. Входы: независимые `drafts/ui.before.md` и
`drafts/logic.before.md`; журналы отдельных агентных сессий в `evidence/`.
Решения ниже принял основной агент в пределах поручения выполнить работу.
Они не выдаются за ответы или приёмку человека.

| Вопрос / исходные варианты | Решение и причина |
|---|---|
| UI: плоская ошибка; логика: error.code/message | Общая оболочка error.code/message + request_id; одинаковая обработка 413/422/502/504 |
| request_id в успехе? | Только X-Request-ID во всех ответах; тело 200 сохраняет OUT-1 |
| Как вызвать медленную LLM? | X-Demo-Scenario: normal/slow/error/invalid; отдельный header не загрязняет diff |
| Клиент ждёт 10 или 15 секунд? | Сервер 10; браузер 15 как транспортный fallback; 504 означает timeout, обрыв сети — error |
| Повтор автоматически? | Только вручную; ввод остаётся в textarea, повторной отправки во время loading нет |
| Что значит символ? | Unicode code point, Python len и JS Array.from; emoji проверяются на границе |
| Где существующее приложение? | В P1 только TRAINING_PR.diff. До рефакторинга восстановить baseline из добавленных строк; не заявлять о существовавшем runnable backend |
| Нужно ли подключать платную LLM? | Нет. Детерминированный async provider позволяет проверить таймаут, отмену и восстановление без ключей |
| Какие секреты маскируются? | PEM private key, Bearer, известные token prefixes, присваивания password/token/secret/api_key; границы эвристики документировать |
| Когда архивировать? | Не заявлять человеческую приёмку и не архивировать от её имени; работа остаётся review-ready |

DoR: источник US найден; 5 AC, ошибки, границы и контракт определены;
обе команды подтвердили финальные документы до кода. DoD: тесты прошли,
10-секундный timeout и retry видны в браузере, артефакты и инструкции
проверены; окончательная оценка/приёмка остаётся человеку.
