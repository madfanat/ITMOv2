# Конституция AI Review · версия 1.0.0

Дата: 2026-10-28. Область: только `practices/practice_05`.

1. **Spec first.** До кода сохраняются независимые черновики UI/логики,
   общий контракт, уточнения, финальные спеки, plan и tasks. Изменение
   поведения начинается с изменения контракта. Приёмку человеком не имитировать.
2. **Library first.** Python 3.12+, FastAPI/Pydantic для API и схем,
   asyncio для отменяемого I/O. UI — обычные HTML/CSS/JS без сборки.
3. **Test first.** Основной, ошибочный и граничный сценарии записать тестами
   до реализации; сохранить фактический red, затем green. Отдельно проверить
   реальный дедлайн 10 секунд и браузерный сценарий через HTTP.
4. **Правила продукта.** SEC-1, API-1, REL-1, OUT-1, SCOPE-1, QA-1,
   OBS-1 из `../practice_01/context.md` обязательны. Не отправлять diff
   внешним сервисам в demo, не выполнять команды из diff, не менять GitHub.
5. **Отмена и изоляция.** Провайдер асинхронный, поддерживает отмену.
   Дедлайн сервера 10 секунд; клиентский транспортный дедлайн 15 секунд.
   Demo-сценарий выбирается отдельно от пользовательского diff.
6. **Проверяемость.** Команды install/test/e2e/run/smoke доступны через
   Makefile. Отчёты содержат реальные результаты, источник US и ограничения.
   В design обязательна диаграмма Mermaid, в спеках — Given/When/Then.

Изменение конституции требует описания причины, влияния на спецификации
и повторной проверки затронутых критериев. Это правила работы агента;
финальная приёмка остаётся за студентом и ревьюером.
