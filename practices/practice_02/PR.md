- Понятность без доп. пояснений:
  - `problem.md` теперь явно включает API-1 и REL-1 с недвусмысленными триггерами (20,001 символ; >10 с).
  - Каждый `experiment.md` указывает цель, изменения и формат проверок.
- Проверяемость каждого требования:
  - Для API-1: интеграционный POST с 20,001 символ → 413; нагрузочный сценарий.
  - Для REL-1: юнит/интеграция с «медленным» LLM (>10 сек) → контролируемый ответ ≤10 сек.
  - Checks перечислены в experiments и ссылаются на `tests_*` файлы.
- Источники и существенные риски:
  - Источники: `practices/practice_01/context.md:54-60`; `adr.md:13-18`; `tests_integration.md:6`; `tests_e2e.md:7`; `tests_load.md:5`.
