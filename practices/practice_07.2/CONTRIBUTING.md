# Как оформить обращение

- Для бага укажите версию, шаги воспроизведения, фактический и ожидаемый результат.
- Для вопроса опишите цель и перечислите, что уже проверили.
- Для новой возможности опишите сценарий использования и желаемое поведение.

Используйте тестовые данные в примерах и вложениях.
