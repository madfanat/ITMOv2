# Работа с AI

Codex спроектировал HTML-прототип, реализовал интерфейс и подготовил проверки. Chromium через Playwright использовался для сверки макета и приложения, снимков и повторяемых тестов. Ниже приведены краткие формулировки рабочих запросов, которые направляли каждый этап.

| Этап | Пример запроса | Что изменилось после проверки |
| --- | --- | --- |
| Макет | «Спроектируй на HTML интерактивный макет для дежурного поддержки. Покажи ввод заголовка и описания, ожидание, категорию, ручной разбор и ошибку. На телефоне форма должна идти перед результатом». | Сохранили две карточки и основной порядок действий. После сравнения с браузерным рендером скорректировали высоту шапки, обновили подпись необязательного поля, добавили счётчик и выделили ручной разбор отдельным цветом. Исправили `hidden`, который в первом прототипе перекрывался стилями ошибки. |
| Интерфейс | «Реализуй макет на React и TypeScript. Переиспользуй Button, TextInput, Textarea, Paper, Alert и Progress из Mantine. Запускай классификатор 7.2 через n8n. Во время ожидания принимай только одну отправку». | Вынесли серверную и клиентскую валидацию в один модуль. Выделили `classification: null` для ручного разбора и оставили введённый текст при сбое. Первый прогон выявил конфликт стилей контура фокуса с Mantine. Уточнили селектор и проверили вычисленные `outline-style` и `outline-width`. |
| Тесты | «Напиши Playwright-проверки формы по доступным подписям. Подмени ответы на HTTP-границе. Удерживай запрос для проверки двойного клика и Enter, проверь результат, пустой ответ, ошибку и повтор». | Добавили проверку точного тела POST и одного запроса до и после снятия задержки. Проверка восстановления повторяет запрос с теми же данными. Удаление рендера `Alert` в пробной правке уронило тест; после восстановления все восемь тестов прошли. |

AI-классификатор работает отдельно от инструментов разработки. На учебном n8n API вызывает исходный Sub-workflow практики 7.2. В одном из прогонов для `feature` модель вернула `confidence: 0. nine`, и Structured Output Parser отклонил ответ. В модельной ноде включили JSON-режим VseLLM. Structured Output Parser продолжает проверять поля, тип категории и числовую уверенность.
