# План лабораторной 7.1

1. Изучить лекцию о триггерах, JSON между нодами и истории запусков. Сверить учебный шаблон и слайды практики с четырьмя критериями из условия.
2. Ограничить автоматическое ревью событием открытия PR. Развести точные команды `/make_ai_review` и `/make_other_ai_review`, подключить две разные модели и указывать модель в опубликованном ревью.
3. Создать Data Table, проверить наличие глобального GitHub ID перед основным ревью и сохранить ID после успешной публикации. Оставить вторую модель доступной для сравнения на том же PR.
4. Разобрать unified diff, выделить непрерывные группы изменений и привязать каждую к строке и стороне diff. Публиковать комментарии одним GitHub review и проверять SHA перед отправкой.
5. На тестовом PR проверить открытие, обе команды, дедупликацию и точечные комментарии. Сопоставить ответ модели, запись в Data Table и опубликованное ревью. Сохранить реальные скриншоты из Executions и Data Tables.
6. Экспортировать импортируемый workflow без секретов, собрать подтверждения по критериям и подготовить текст PR.
